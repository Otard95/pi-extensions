# pi-extensions

## Scripts

| Command | Description |
|---|---|
| `pnpm run check` | TypeScript type check (errors only) |
| `pnpm run check:full` | Full diagnostics incl. suggestions (TS80007 etc.) |
| `pnpm run lint:fix` | Biome lint + auto-fix |
| `pnpm run test` | Run tests |

## Development dependencies

Keep the development dependencies in `./package.json` up to date
with:
```bash
pi --version
```
